## Known non-blocking issues

- `shellcheck` 0.11 (current Homebrew) flags pre-existing warnings in
  `scripts/g6-checkpoint-secret-policy.sh`, `scripts/i18-agent-package-smoke.sh`,
  and `scripts/test-g6-ha-pitr-workflow.sh`; the pinned CI toolchain passes.
  The shellcheck version is not pinned in `toolchains.lock`.
- The rpm leg of the published-baseline upgrade smoke is not implemented
  (the deb leg runs on both release architectures); the rpm cross-version
  upgrade remains covered by the fabricated-version smoke and the native
  package scriptlets are architecture-independent.
- The rollout batch header aggregates failed counts but not a separate
  skipped count; per-node skipped states and reasons are displayed.

## Final verdict

READY FOR v0.2.0.

The frozen candidate satisfies the repository's v0.2 engineering
release-readiness gates: required CI on the exact SHA, migrations on both
PostgreSQL majors, the full package matrix including the real v0.1.1 → 0.2.0

the GitHub Release, or any production release asset; publishing remains a
